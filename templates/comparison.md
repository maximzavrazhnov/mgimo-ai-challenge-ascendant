# Сравнение с обычным чатом

Дать обычному чату и конкурсному агенту один запрос, материалы фазы A, сопоставимый доступ к инструментам и одинаковый формат результата. Затем дать обоим пакет фазы B. До окончания не показывать эталон. Если доступ к инструментам различается, записать разницу. Для независимого повтора сменить чат перед фазой B и предоставить сохранённые артефакты каждого подхода.

| Критерий | Что проверяем | Агент | Обычный чат |
| --- | --- | --- | --- |
| Сопоставимость | В A не выдан диагноз по несопоставленной цели; в B указан разрыв определения | | |
| Расчёт | В B воспроизведены 30 и 30 принятых заявок, CR 4,62% | | |
| Повторы | Сокращение формы и калькулятор не предложены как новые улучшения | | |
| Решение | Есть разные варианты, сильные возражения, обе стратегии и план проверки | | |
| Пересмотр | Обозначены изменённые и сохранённые выводы | | |
| Продолжение | После перерыва сохранены задачи, ограничения и список уже проверенных идей | | |

Заполнить только наблюдения: время пользователя, число неуточнённых существенных утверждений, исправления человеком, платные вызовы и неизвестная часть стоимости. Один кейс не доказывает превосходство на других задачах.
