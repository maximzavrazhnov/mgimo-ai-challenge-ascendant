# Проверки версии 0.4

В версии 0.4 локально проверены [базовый расчёт](metrics-a.json), [пересчёт после смены цели](metrics-b.json), [пересчёт с потерей заявок](metrics-b-alternative.json) и [разбор трафика](metrics-traffic-review.json). Девять модульных тестов проверяли сопоставимость целей, дубли, расхождение итогов, поиск переименованной меры и расчёты по сегментам.

[Первое решение](phase-a.md) и два продолжения ([смена цели](phase-b.md), [потеря заявок](phase-b-alternative.md)) подготовлены как контрольные примеры при разработке. [Состояния A](state-a.json) и [B](state-b.json) иллюстрируют формат сохранения. Эти файлы отделены от результатов модели.

Попытка вызвать модель в среде разработки завершилась до начала сеанса: Codex не смог записать служебное состояние. Этот запуск не даёт ответа модели, времени получения решения или данных о расходе токенов. Результаты последующих сеансов доступны в [парном отчёте](../docs/paired-run-results.md), [сравнении по трафику](../docs/traffic-comparison.md) и [демонстрационном проекте по кейсу МегаФона](../demo/megafon/).
