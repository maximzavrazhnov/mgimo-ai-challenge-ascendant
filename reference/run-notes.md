# Что проверено в версии 0.4

- В среде разработки выполнен исходный расчёт и два взаимоисключающих пересчёта: metrics-a.json, metrics-b.json, metrics-b-alternative.json. Для известных мер проверены ID и алиасы. Расчёт не делает заключений о причинности.
- Девять модульных тестов проверяют сопоставимость цели, пересчёт и различимость веток, дубли строк, конфликт итогов, обнаружение переименованной меры, разрезы трафика, разложение изменения CR и отсутствие наблюдений по сегменту.
- Расчёты дополнительного кейса сохранены в metrics-traffic-review.json, критерии решения даны в traffic-review.md. Тесты проверяют расчёт, а не то, одобрит ли независимый агент безопасное решение о трафике.
- Сценарий сравнения прогонялся на подготовленных данных, но вызов модели в обоих вариантах завершился до старта сессии: служебное состояние CLI недоступно для записи в среде разработки. Ответы, потребление токенов и оценка качества отсутствуют. Замер запуска с ошибкой не является временем ответа. Проверка формирования файлов и раздельности входов выполнена локально.
- phase-a.md, phase-b.md и phase-b-alternative.md представляют демонстрацию логики, подготовленную при разработке. Это не независимый повтор в новой агентной среде.
- Черновые состояния A и B находятся в reference/. Они служат проверочными примерами структуры и не являются активным состоянием следующего запуска.
- Не измерены время пользователя, стоимость модели, выигрыш относительно обычного чата. Не пройдены отдельный новый чат, независимый запуск и второй кейс. Не записано видео; нет финального описания для сдачи. Отдельный бриф МегаФона не предоставлен по сообщению пользователя. Учебный пример не заявлен как утверждённая замена возможного отдельного задания.
