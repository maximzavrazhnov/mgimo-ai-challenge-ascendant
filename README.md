# Стратег Фабрики продуктов

**Команда Ascendant · МГИМО AI Challenge · кейс МегаФона**

ИИ-агент помогает руководителю решить, тестировать ли предупреждение об исчерпании семейного пакета. Агент разбирает бриф, вызывает калькулятор, сравнивает варианты, готовит продуктовую и коммуникационную стратегии и пересматривает рекомендацию в новом сеансе при изменении данных. Решение о запуске принимает руководитель.

В учебном сценарии для исходной проверки нужны 3 276 семей, или 546 в неделю при наборе за шесть недель. При обновлённом темпе 150 семей в неделю в это окно помещаются 900 семей. Агент разделяет проверку процесса за шесть недель и набор для оценки эффекта: 22 недели при том же темпе плюс семь дней наблюдения после включения последней семьи. Фактический эффект предупреждения не измерялся. Сценарные данные не являются внутренними данными МегаФона.

## Быстрый старт: проверка без модели

Клонируйте репозиторий или распакуйте ZIP из GitHub. Откройте терминал в папке, где находится этот README. Нужен **Python 3.10 или новее**. Для команд ниже не требуются сеть, ключи или дополнительные пакеты. Если в вашей системе команда называется `python3`, замените `python` на `python3`.

```sh
python tools/operator_model.py demo/megafon/assumptions.json
python continuation/start.py --check
python tools/demo_megafon_review.py --choice observe
python -m unittest discover -s tests -v
```

Первый скрипт считает исходный сценарий. Второй проверяет контрольные суммы состояния и воспроизводит расчёт пересмотра, ожидаемый финал: `CHECK OK`. Третий показывает, как карточка руководителя переходит из `current` в `needs_review` при изменении входа во временной копии. Это проверки кода; они не вызывают модель.

## Запуск агента

Для нового сеанса нужен [Codex CLI](https://developers.openai.com/codex/cli) в `PATH`, выполненный вход и доступ к модели. Проверьте `codex --version` и `codex login status`. На Windows команды запускаются из PowerShell, на macOS и Linux из терминала.

```sh
python tools/run_comparison.py eval-megafon --scenario megafon --arm agent --timeout 600
python continuation/start.py --timeout 600
```

- **Исходный прогон** пишет итог и статус в `eval-megafon/results.json`, ответ и состояние в `eval-megafon/agent-megafon/runs/`. Для нового прогона укажите ещё не существующую папку вместо `eval-megafon`. Для повторения незавершённого этапа используйте `python tools/run_comparison.py eval-megafon --resume --timeout 600`.
- **Продолжение** открывает новый сеанс на базе **приложенного состояния v1**, не на базе файла, только что созданного первой командой. Путь к результату выводится в строке `Saved revision:`; журнал находится в `continuation/run-.../`. Если модель недоступна, сохранённые v1/v2 и проверки без модели остаются доступны.

За дополнительными расчётами и диагностикой обращайтесь к [маршруту для жюри](docs/jury-guide.md) и [инструкции второго сеанса](continuation/README.md).
