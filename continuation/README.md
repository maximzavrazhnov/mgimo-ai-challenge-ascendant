# Продолжение кейса МегаФона

Вторая сессия использует приложенное решение v1 и учебное обновление темпа набора. Она пересматривает рекомендацию, не меняя сохранённые входы. Данных об эффекте пилота нет.

Из корня репозитория:

```sh
python continuation/start.py --check
python continuation/start.py --timeout 600
```

Первая команда проверяет сохранность состояния и пересчитывает план без модели. Для второй нужны Python 3.10 или новее, Codex CLI в `PATH` и вход в аккаунт с доступом к модели. Она берёт состояние из `case/baseline/`, даже если только что выполнен новый первый прогон. На Windows команды работают из PowerShell.

Каждая попытка пишет в отдельный каталог `continuation/run-.../`. Пока в терминале видна строка `Starting a new Codex session`, вывод идёт в журнал. При успехе строка `Saved revision:` содержит путь к ZIP с решением, расчётом и сводкой. При сбое проверьте `codex.stderr.log` и `summary.json` в том же каталоге.

## Как читать результат

1. В исходном решении: объём 3 276 семей, ориентир 546 в неделю, шесть недель набора и ещё 7 дней на наблюдение.
2. В `case/update/recruitment.json`: теперь доступны 150 подходящих семей в неделю, это учебный вход. Запуск начинает новый сеанс и использует сохранённое состояние.
3. В [пересмотренном решении](case/results/decision-v2.md): 900 семей за 6 недель, недобор 2 376. При текущем темпе потребуется 22 недели набора и ещё 7 дней наблюдения после включения последней семьи. За шесть недель проверяется процесс; для оценки эффекта нужен полный набор.

Скрипт сверяет структуру результата, числа, сохранность входов и вызов калькулятора. Полный журнал `codex.jsonl` находится в папке запуска, рядом с ZIP.
