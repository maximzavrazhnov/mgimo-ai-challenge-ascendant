# Демонстрационный проект по кейсу МегаФона

Руководителю нужно решить, выделять ли ресурс на пилот раннего предупреждения об исчерпании семейного пакета. Демонстрация показывает исходное решение агента и повторный сеанс, в котором новый темп набора меняет рекомендацию.

## Итоговые стратегии

- [Продуктовая стратегия](../../docs/megafon-submission-strategy.md#1-клиент-и-проблема): предупредить организатора до ограничения, если подтверждены права доступа и есть свободный объём. Условия допуска и критерии пилота приведены в разделах 3–5.
- [Коммуникационная стратегия](../../docs/megafon-submission-strategy.md#2-предложение-и-коммуникация): объяснить, что изменилось и что организатор может сделать в приложении. Подтвердить только выполненную операцию.

Итоговый документ включает редакцию команды после прогонов. Исторические ответы агента сохранены отдельно по ссылкам выше. Данные и числа учебные; фактический эффект предупреждения и его окупаемость не измерялись. Решение о запуске остаётся за руководителем.
