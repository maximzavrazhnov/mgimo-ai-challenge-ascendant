# Подтверждённые возможности и ограничения

Два сеанса в Windows показывают работу агента: вызов расчёта, сравнение альтернатив, сохранение состояния и пересмотр рекомендации после изменения темпа набора. Сценарий воспроизводится по [инструкции](../README.md). Локальные проверки не требуют доступа к модели.

После сеансов команда уточнила текст предупреждения, разделила паузу и закрытие инициативы, добавила прогноз по каналам, когортный расчёт и оценку задержки запуска. Результаты исторических сеансов сохранены отдельно от [итоговой стратегии](megafon-submission-strategy.md). Для контрольного сценария с QA подготовлены входы; сохранённого модельного результата нет.

Публичный PDF проверен отдельным скриптом. Самостоятельное обращение агента к сайту и живое уточнение неполного запроса в исторических сеансах не показаны. Денежная стоимость прогонов, реальный эффект и окупаемость пилота не измерялись.
