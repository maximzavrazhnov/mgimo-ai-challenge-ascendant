# Готовность конкурсного пакета

Подтверждены запуск агента, два реальных сеанса в Windows, расчёты, три исходные альтернативы, сохранение состояния и пересмотр после изменения темпа набора. Анализ данных и пересмотр при новых данных закрыты; CLI работает.

В этой сборке команда отдельно исправила предупреждение до ограничения, разделила паузу и отказ от инициативы, добавила вычисление платёжного эффекта по месячным когортам и объединила артефакты двух сеансов. Это не меняет содержание исторических выводов агента. Реальные данные по окупаемости, доказанный эффект пилота, имя модели в исходном журнале и измеренная стоимость человеком отсутствуют.

22 ноября проверен отдельный сетевой инструмент на реальном публичном PDF, протокол в evidence/megafon/public-web-receipt.json. Карточка решения теперь замечает изменения перечисленных исходников до записи нового ответа.

До подачи: показать вызов веб-инструмента из сеанса конкурсного агента и короткий пример уточнения неполного запроса; запись сквозного демо; публикация согласованных файлов и проверка ссылок в режиме проверяющего; актуальные согласия и допуск участников в кабинете. Дедлайн по [официальному регламенту](https://challenge.mgimo.ai/rules): 22 ноября 2026, 23:59 МСК. Капитан проверяет и отправляет сам. Данные PolyTeam и рабочие материалы в этот архив не включены.
