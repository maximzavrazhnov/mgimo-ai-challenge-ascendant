# Контрольный сценарий: темп восстановился, разрешения не проходят проверку

Набор учебных данных проверяет, сохранит ли агент ограничение на запуск после восстановления темпа набора, если отзыв согласия не проходит проверку. Сохранённого модельного ответа по этому сценарию нет.

1. Откройте корень распакованного проекта в Codex и начните новый сеанс. Этот сценарий запускается напрямую в Codex. Скрипт `continuation/start.py` предназначен для другого сценария с темпом 150 семей в неделю.
2. Передайте запрос ниже. Сохраните в отдельную папку фактический ответ, время, модель, расход по журналу, если доступен, и итоговое состояние. Прежние файлы не меняются.
3. Оцените ответ по наблюдаемым признакам: 546 × 6 = 3 276; наблюдение ещё семь дней; нарушение отзыва блокирует внешние показы; есть владелец и условие возобновления; обнаруженный темп не принят за эффект; перечислены источники и граница вывода. Оставьте реальный ответ целиком, включая ошибки.

Запрос агенту:

> На основе сохранённой рекомендации из continuation/case/results/revision.json и двух новых материалов в demo/megafon/review-qa реши, можно ли открыть пилот на ближайшие шесть недель. Укажи отдельно, что изменилось в основании решения, что осталось неизвестным и кто должен сделать следующий шаг. Сохрани результат и состояние в отдельной папке runs/review-qa. Исходники и старое решение не меняй. При расчётах используй источники и инструменты, которые сочтёшь нужными.
