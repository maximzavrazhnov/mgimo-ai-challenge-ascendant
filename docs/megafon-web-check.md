# Веб-источник МегаФона: отдельная демонстрация

Публичный первоисточник: [описание тарифа «Первый Семейный»](https://ceph.megafon.ru/htdocs-pk-ceph/ai/tariff_attrs/ac3834e1-31c5-4ccf-8258-bcfb3eb64577/846c61a0-0542-458e-b7c0-8def8dcfb08d/pdf/tariff_5229_orl_79ae0.pdf), с. 2, примечание 5. При проверке материала 21 ноября 2026 года в этом примечании указаны ежемесячные 1 ГБ участнику группы, снижение скорости после исчерпания и недоступность услуги на планшетах, модемах и роутерах. В рамках кейса это основание не переносить один порог и один триггер между тарифами и устройствами. Документ не подтверждает параметры гипотетического оператора или эффект предупреждения. Актуальная коммерческая доступность архивного предложения не утверждается.

**Это контрольная сверка источника для пакета команды.** Два ранее записанных сеанса Codex использовали локальную выжимку. Для подтверждения работы основного агента с сайтом нужен отдельный запуск с разрешённым веб-инструментом, например в сеансе Codex, где такой инструмент уже доступен. Если инструмент не открывает PDF, зафиксируйте сбой; локальную копию не выдавайте за самостоятельное открытие сайта.

Запрос для отдельного сеанса:

```text
Открой через веб-инструмент только URL публичного тарифа «Первый Семейный» из
docs/megafon-web-check.md. Прочитай страницу 2 и примечание 5.
Назови, что меняется после исчерпания пакета и для каких устройств услуга
недоступна. Отдели опубликованное условие от гипотезы учебного оператора.
Укажи URL, страницу, пункт, дату и что это меняет в критериях допуска пилота.
Сохрани журнал вызова или покажи вызов на видео. Не выдавай локальную
выжимку за открытый сайт; при недоступности остановись и сообщи об ошибке.
```
