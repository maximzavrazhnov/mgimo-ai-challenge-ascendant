# Демонстрационное видео

Ролик длится 5 минут 25 секунд. В нём показаны результаты и журнал сохранённых сеансов, а не новый запуск в реальном времени.

| Таймкод | Содержание |
| --- | --- |
| 0:00 | Задача руководителя и исходный запрос |
| 0:26 | Вызов калькулятора в журнале первого сеанса |
| 1:19 | Варианты решения и различие между паузой и закрытием |
| 2:03 | Продуктовая и коммуникационная стратегии, план пилота |
| 2:57 | Сохранённое состояние и новые данные о темпе набора |
| 3:17 | Журнал второго сеанса, результат расчёта и пересмотр |
| 3:52 | Новый план: проверка процесса или более долгий набор для оценки эффекта |
| 4:48 | Ограничения открытого источника, карточка решения и итоговая рекомендация |

Данные учебные. Веб-источник проверялся отдельно, а результаты эксперимента с клиентами не измерялись.
