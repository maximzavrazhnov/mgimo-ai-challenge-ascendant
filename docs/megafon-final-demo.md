# Дополнительные проверки агента

Сохранённые результаты основного сценария доступны в [демонстрационном проекте](../demo/megafon/). Ниже приведены способы проверить дополнительные возможности.

## Внешний источник

Из корня проекта: `python tools/check_megafon_source.py`. Проверка содержит один публичный URL, не принимает произвольные адреса и не переходит по редиректам. Через Python загружает PDF и читает страницу 2. Для этого шага нужен доступ к ceph.megafon.ru и либо Python-пакет pypdf (`python -m pip install pypdf`), либо уже установленный pdftotext. Историческим прогонам и локальным расчётам этот пакет не нужен.

Реальная техническая проверка от 22.11.2026: [протокол](../evidence/megafon/public-web-receipt.json). Формулируйте вывод осторожно: документ касается конкретной опубликованной редакции и иллюстрирует, что критерий допуска зависит от тарифа и устройства. Он не подтверждает текущую доступность тарифа, доступность общего пакета в учебном кейсе или эффект уведомления.

Чтобы показать вызов самим агентом, попросите Codex из корня проекта в сеансе с разрешённым доступом к этому публичному адресу: «Проверь, почему пилот семейного предупреждения нельзя переносить на роутеры. Используй только утверждённый публичный источник и инструмент check_megafon_source.py; назови страницу и объясни, что меняется в правилах допуска. Если сеть недоступна, отметь это». Если доступен собственный веб-инструмент среды, он также подходит: покажите фактический вызов источника и ответ. Успешный прямой запуск Python показывает работу инструмента; он не доказывает вызов из отдельного сеанса Codex.

## Постановка неполного запроса

Сначала дайте агенту только: «Нужно решить, что делать, если темп набора семей оказался ниже ожидаемого. Прежде чем делать вывод, уточни только то, что меняет решение, и дождись ответа». Ожидаются 1–2 полезных вопроса, например, что именно руководство хочет утвердить и есть ли подтверждённый темп или срок. Отвечайте во втором сообщении: «Нужно выбрать между продлением и шестинедельной проверкой процесса. Подтверждённой мощности на коротком окне нет: условно доступны 150 семей в неделю». Запишите реальные вопросы. Если агент сразу пишет решение или вновь спрашивает то, что уже известно, не засчитывайте этот этап.

## Решение руководителя

Покажите фазу «совет агента → выбор человека → пересмотр при изменении входа». В проверочной папке отдельное изменение учебных данных должно переводить карточку из current в needs_review до переписывания ответа. Актуальность отслеживается по выходам и известным входным файлам. Не выдавайте учебный выбор человека за согласование пилота МегаФоном. Из корня запустите `python tools/demo_megafon_review.py --choice observe` (или передайте свой учебный выбор: pilot, revise, observe, stop). Команда показывает оба статуса на отдельной временной копии.
